Fase 1: Preparação & Conceito Fundamental Estudo Prévia

Como Capturar Elementos do HTML com JavaScript

Antes de abrir o cofre, estude como o JavaScript se conecta com a página web (DOM): 

const numeroSenha = document.querySelector('.parametro-senha__texto');
let tamanhoSenha = 12;
numeroSenha.textContent = tamanhoSenha;
1. Seleção no DOM

document.querySelector('.classe') busca e captura o elemento HTML que possui a classe CSS especificada.

2. const vs let

Usamos const para dados/elementos fixos e let para variáveis cujo valor vai mudar (como o número de caracteres).

3. Exibição na Tela

A propriedade .textContent altera diretamente o texto visível dentro da tag HTML na página.

Eventos de Clique e Validação com 'if'

Aprenda como controlar o tamanho da senha com botões sem deixar o valor ficar menor que 1: 

const botoes = document.querySelectorAll('.parametro-senha__botao');
botoes[0].onclick = diminuiTamanho;

function diminuiTamanho() {
    if (tamanhoSenha > 1) {
        tamanhoSenha--;
    }
    numeroSenha.textContent = tamanhoSenha;
}
1. querySelectorAll e ÍNDICES

Pega TODOS os botões da classe. botoes[0] representa o primeiro botão (-) e botoes[1] o segundo (+).

2. Validação Lógica 'if'

A instrução if (tamanhoSenha > 1) só autoriza o decremento se o tamanho for estritamente maior que 1. Se for 1, o código interno NÃO roda!

3. Operador Decremento (--)

tamanhoSenha-- é uma atalho curto em JS para subtrair 1 unidade da variável (tamanhoSenha = tamanhoSenha - 1).

Fase 3: Preparação & Conceito Fundamental Estudo Prévia

Sorteio Aleatório de Caracteres com Math API

Entenda como o JavaScript sorteia letras do alfabeto para montar a senha: 

let numeroAleatorio = Math.random() * alfabeto.length;
numeroAleatorio = Math.floor(numeroAleatorio);
senha += alfabeto[numeroAleatorio];
1. Math.random()

Gera um número decimal aleatório entre 0 e 1 (ex: 0.7482). Multiplicando por alfabeto.length, o resultado fica na faixa do tamanho da lista.

2. Math.floor()

Arredonda SEMPRE o número decimal para baixo (ex: 18.9 vira 18). Isso é essencial para gerar índices inteiros válidos de textos/arrays!

3. Concatenação de Letras

alfabeto[numeroAleatorio] pega o caractere daquela posição e o operador += junta a letra na senha final.

Fase 3: O Sorteio do Alfabeto Desafio 3/4

Observe a geração de índices aleatórios:

let numeroAleatorio = Math.random() * alfabeto.length;
numeroAleatorio = Math.floor(numeroAleatorio);

Por que usamos a função Math.floor() logo após gerar o numeroAleatorio?

❌ Acesso Negado!

Math.random() gera decimais (ex: 3.8471). Índices de arrays e strings no JS precisam ser números inteiros. O Math.floor() descarta as casas decimais arredondando para baixo!

Entropia & Força Matemática de Senhas

Aprenda como os especialistas em Segurança da Informação usam matemática para medir a força de uma senha: 

let entropia = tamanhoSenha * Math.log2(tamanhoAlfabeto);
if (entropia > 57){ 
    forcaSenha.classList.add('forte'); 
}
1. Conceito de Entropia

Mede o grau de imprevisibilidade e aleatoriedade de uma informação (medida em bits).

2. Ataques de Força Bruta

Quanto maior a entropia, mais combinações por segundo um supercomputador precisará tentar para tentar adivinhar a senha.

3. Math.log2()

Função matemática em JS que calcula quantos bits de segurança cada caractere adiciona à senha com base na diversidade do alfabeto usado.

// ===== ESCAPE ROOM JS: GERADOR DE SENHAS COMPLETO =====

// 1. SELEÇÃO DE ELEMENTOS E VARIÁVEIS INICIAIS
const numeroSenha = document.querySelector('.parametro-senha__texto');
let tamanhoSenha = 12;
numeroSenha.textContent = tamanhoSenha;

const letrasMaiusculas = 'ABCDEFGHIJKLMNOPQRSTUVXYWZ';
const letrasMinusculas = 'abcdefghijklmnopqrstuvxywz';
const numeros = '0123456789';
const simbolos = '!@%*?';

const campoSenha = document.querySelector('#campo-senha');
const checkbox = document.querySelectorAll('.parametro-senha__checkbox');
const botoes = document.querySelectorAll('.parametro-senha__botao');
const forcaSenha = document.querySelector('.forca');

// 2. CONTROLE DE TAMANHO DA SENHA
botoes[0].onclick = diminuiTamanho;
botoes[1].onclick = aumentaTamanho;

function diminuiTamanho() {
    if (tamanhoSenha > 1) {
        tamanhoSenha--;
    }
    numeroSenha.textContent = tamanhoSenha;
    geraSenha();
}

function aumentaTamanho() {
    if (tamanhoSenha < 20) {
        tamanhoSenha++;
    }
    numeroSenha.textContent = tamanhoSenha;
    geraSenha();
}

// 3. GERAÇÃO DA SENHA ALEATÓRIA
function geraSenha() {
    let alfabeto = '';
    if (checkbox[0].checked) { alfabeto += letrasMaiusculas; }
    if (checkbox[1].checked) { alfabeto += letrasMinusculas; }
    if (checkbox[2].checked) { alfabeto += numeros; }
    if (checkbox[3].checked) { alfabeto += simbolos; }

    let senha = '';
    for (let i = 0; i < tamanhoSenha; i++) {
        let numeroAleatorio = Math.floor(Math.random() * alfabeto.length);
        senha += alfabeto[numeroAleatorio];
    }
    campoSenha.value = senha;
    classificaSenha(alfabeto.length);
}

// 4. CÁLCULO DE ENTROPIA E CLASSIFICAÇÃO DA FORÇA
function classificaSenha(tamanhoAlfabeto) {
    let entropia = tamanhoSenha * Math.log2(tamanhoAlfabeto);
    forcaSenha.classList.remove('fraca', 'media', 'forte');

    if (entropia > 57) {
        forcaSenha.classList.add('forte');
    } else if (entropia > 35) {
        forcaSenha.classList.add('media');
    } else {
        forcaSenha.classList.add('fraca');
    }
}

// Inicializa a primeira geração de senha
geraSenha();
